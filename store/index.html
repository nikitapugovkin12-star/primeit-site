    Короткие ответы

    Какие языки поддерживает RunCode?

    TypeScript, JavaScript, Python, Go, Rust, Java, C#, PHP, SQL и ещё около тридцати. Лучше всего агент работает в проектах с тестами.

    Мой код уходит с компьютера?

    Только файлы, нужные для задачи, и только после вашего подтверждения. В self-hosted режиме код вообще не покидает вашу инфраструктуру.

    Можно использовать свой ключ модели?

    Да. RunCode работает с ключом вашего провайдера, и оплата токенов идёт напрямую через него.

    Чем это отличается от автодополнения?

    Автодополнение дописывает строку. RunCode берёт задачу целиком: правит несколько файлов, запускает тесты и возвращает готовый diff.

    Как оплатить подписку?

    Подписка оплачивается в USDT. Онлайн-оплата на сайте сейчас подключается — оформите заказ, и мы пришлём реквизиты для оплаты.
